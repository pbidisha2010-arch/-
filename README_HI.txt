RAMAN DULARI – Free PWA Starter

यह शुरुआती वेबसाइट/PWA starter है, Play Store APK/AAB नहीं।

मुफ्त hosting का एक तरीका:
1. माता-पिता/guardian की मदद से GitHub account बनाएं और नया public repository बनाएं।
2. ZIP की सभी files repository के root में upload करें।
3. Repository → Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. HTTPS URL बनने पर Android Chrome में खोलें।
5. Chrome menu (⋮) → Install app या Add to Home screen चुनें।

ध्यान दें:
- GitHub Pages की interface/settings बदल सकती हैं।
- अपनी अनुमति-प्राप्त audio files चुनकर player में सुनें।
- चुनी हुई audio files अभी app में स्थायी रूप से upload नहीं होतीं।
- Copyright वाले भजन/कथा publish करने से पहले अनुमति लें।
- यह installable website/PWA है, Play Store listing नहीं।
